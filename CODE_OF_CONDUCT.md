# Code of Conduct

This project expects respectful, constructive participation from everyone involved.

## Expected behavior

- Be direct, but remain respectful.
- Assume good intent until there is clear reason not to.
- Focus criticism on code, design, and behavior rather than people.
- Share context that helps others reproduce issues or understand proposals.
- Accept maintainers' decisions on scope, quality, and release timing.

## Unacceptable behavior

- Harassment, threats, discrimination, or intimidation.
- Personal attacks, insults, or repeated hostile behavior.
- Publishing private information without consent.
- Deliberate disruption, spam, or bad-faith issue and pull request activity.

## Enforcement

Maintainers may edit, lock, hide, or remove content that violates these standards. They may also restrict participation when necessary to protect the project and its contributors.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers through the security reporting path in [SECURITY.md](./SECURITY.md) or by opening a private GitHub security advisory when appropriate.
