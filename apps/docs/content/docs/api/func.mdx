# preludejs/Func API Reference

## Core

### apply <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Returns the application of the supplied list as arguments to the supplied function.

```typescript
function apply<A extends readonly unknown[], R>(fn: (...args: A) => R, args: A): R
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(...args: A) => R` |  |
| `args` | `A` |  |

#### Example

```ts
apply((a: number, b: number) => a + b, [2, 3]) //=> 5
```

### compose <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Performs right-to-left function composition. The rightmost function may have
any arity; the remaining functions must be unary.

```typescript
function compose<Fns extends readonly AnyFn[]>(...fns: Fns): Compose<Fns>
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fns` | `Fns` |  |

#### Example

```ts
compose((x: number) => x + 1, (x: number) => -x)(3) //=> -2
```

<hr className="my-8 border-neutral-200 dark:border-neutral-800" />

### const <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Returns the first supplied value and ignores the second.

```typescript
function const<A>(value: A): <B>(_ignored: B) => A
function const<A, B>(value: A, _ignored: B): A
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `value` | `A` |  |

#### Example

```ts
constant('hello')('world') //=> 'hello'
constant('hello', 'world') //=> 'hello'
```

### curry <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Returns a curried version of the supplied function.

```typescript
function curry<A extends readonly unknown[], R>(fn: (...args: A) => R): Curried<A, R>
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(...args: A) => R` |  |

#### Example

```ts
curry((a: number, b: number) => a + b)(1)(2) //=> 3
```

### fix <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Fix-point function for anonymous recursion, implemented with the
[https://en.wikipedia.org/wiki/Fixed-point_combinator#Y_combinator Y combinator](#httpsenwikipediaorgwikifixed-point_combinatory_combinator-y-combinator).

```typescript
function fix<A extends readonly unknown[], R>(fn: (recur: (...args: A) => R) => (...args: A) => R): (...args: A) => R
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(recur: (...args: A) => R) => (...args: A) => R` |  |

#### Example

```ts
fix<[number], number>((recur) => (n) => (n <= 1 ? 1 : recur(n - 1) + recur(n - 2)))(9) //=> 55
```

<hr className="my-8 border-neutral-200 dark:border-neutral-800" />

### flip <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Returns a function with the first two arguments flipped.

```typescript
function flip<A extends readonly unknown[], R>(fn: (...args: A) => R): (...args: Reverse<A>) => R
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(...args: A) => R` |  |

#### Example

```ts
flip(Math.pow)(2, 3) //=> 9
```

### memoize <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

function memoize<A extends readonly unknown[], R>(fn: (...args: A) => R): (...args: A) => R

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(...args: A) => R` |  |

### uncurry <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Applies an array of arguments to a function, which is especially handy for
curried functions.

```typescript
function uncurry<A extends readonly unknown[], R>(fn: (...args: A) => R, args: A): R
function uncurry<A extends readonly unknown[], R>(fn: (...args: A) => R): (args: A) => R
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `fn` | `(...args: A) => R` |  |
| `args` | `A` |  |

#### Example

```ts
uncurry(curry((a: number, b: number) => a + b), [2, 3]) //=> 5
```
