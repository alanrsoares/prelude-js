## Core

### areSimilar <span className="inline-flex items-center rounded-full border border-emerald-200 dark:border-emerald-800 bg-emerald-50 dark:bg-emerald-950/30 text-emerald-600 dark:text-emerald-400 text-xs font-semibold px-2.5 py-0.5 font-medium ml-2 align-middle">ƒ</span>

Performs a deep similarity check across arrays, objects, functions, and
primitive values. Curried, so it can be partially applied.

```typescript
function areSimilar(left: unknown, right: unknown): boolean
```

#### Parameters

| Parameter | Type | Description |
|---|---|---|
| `left` | `unknown` |  |
| `right` | `unknown` |  |

#### Example

```ts
areSimilar({ foo: ['bar'] }, { foo: ['bar'] }) //=> true
```
